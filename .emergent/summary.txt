SCHOOL CLASS AUTHORIZATION:

Never trust a school_id supplied by frontend.

School identity must always be derived server-side:

Bearer access token
→ Supabase Auth user
→ school_accounts.auth_user_id
→ active school account
→ school_id

School class operations must always be scoped to this token-derived school_id.

A school must never be able to read/create/delete another school's classes.

GENERAL ADMIN AUTHORIZATION:

General Admin authorization is backend-first.

Bearer token
→ Supabase Auth verification
→ admin_profiles
→ is_active=true
→ role='general_admin'

Frontend route guards are convenience only.
Final authorization decision belongs to backend.
